# 2026 年 8 月变更记录

## 2026-08-04

- 完成小版本发布同步至 v1.7.7，统一更新应用版本标识、Tauri/Rust 配置、`public/version`、展示页与 `README.md`。
- 新增本次发版说明 `CHANGELOG-v1.7.7.md`，并同步技术文档的当前版本标记。

## 2026-08-03

- 修复 SillyTavern 聊天记录导入只保存会话元数据、重启后正文为空的问题；导入现在显式同步独立消息 Store。
- 统一备份升级为 v4，补齐自定义预设库、独立世界书、记忆词典、事件记忆与时态事实，明文导出统一脱敏所有应用内 API 凭证。
- 新增数据迁移应用服务与原子覆盖仓库；恢复前自动导出脱敏安全快照，正式恢复通过单个 IndexedDB 跨 Store 事务清理并替换用户数据，写入失败时整体回滚。
- 保持旧版备份兼容；旧格式缺少的数据会在确认恢复时明确提示，不静默伪装为完整备份。
- 角色卡本地导入与社区上传单文件上限由 10 MB 统一提升到 20 MB，并同步更新 Rust 服务校验、Nginx 部署示例和网络测试脚本边界。
- 重做角色卡社区的标题区、搜索区与双列卡片层级；列表和详情封面统一使用 `object-contain` 完整等比例展示，不再裁切角色图。
- 完善 SillyTavern Chat Completion 预设导入：优先解析 `character_id: 100001` 编排，保留 Prompt 标识、开关、注入元数据与正则深度字段，支持 `openai_max_tokens`；导入时可选择启用自由编排以完整恢复 Marker 语义，取消则保留原有编排。
- 新增 SillyTavern 预设兼容分析与导入报告，按数据形状识别完整兼容、核心兼容和仅识别预设，显示 Prompt、Marker、正则、TavernHelper 脚本体积、外部网络代码及数据库附着降级项。
- 新增类型化模型请求整形，支持相邻消息合并、system 聚合、角色包装、assistant prefill 与 stop sequences；默认关闭，SillyTavern 标准字段可随预设导入，最终 Prompt 预览与实际发送使用同一结果。
- 将叙事分支升级为受约束的结构化选择协议和原生按钮 UI，支持独立标签、实际输入文本与简短说明；旧字符串数组继续兼容，外部脚本、事件与工具字段一律丢弃。
- 新增会话级 Prompt 场景方案：可把当前区块开关保存为方案并在每个会话独立选择，发送和预览时作为基础编排的非破坏性覆盖层应用；方案缺失或引用旧区块时自动回退并输出诊断。
